# Vexus Music

Музыка, которая просто играет. Поиск по всему, тексты песен строка в строку, клипы, радио со всего мира и эквалайзер — бесплатно и без рекламы.

## Что внутри

**Вся музыка сразу.** Ищите что угодно и слушайте мгновенно: трек подхватывается и начинает играть, пока остальные ещё качаются.

**Тексты песен под музыку.** Строки загораются в такт. Нажмите на любую — трек перемотается ровно туда. Синхронные тексты находятся примерно для половины каталога; там, где их нет, показывается обычный текст или ничего.

**Клипы.** Смахните вбок в полноэкранном плеере — вместо обложки пойдёт видео под ту же музыку. Обложка, текст и клип листаются по кругу.

**Радио со всего мира.** Больше пятидесяти тысяч станций из открытого каталога Radio Browser. В списке только те, что действительно играют: поток каждой проверяется до показа. Станции ведут себя как треки — их можно добавлять в плейлисты и в любимое.

**Эквалайзер.** Восемь полос, которые тянутся пальцем. Настройка запоминается и применяется ко всему, что играет.

**Плейлисты и обмен.** Соберите своё и поделитесь ссылкой — друг заберёт плейлист к себе одним нажатием, копией, которую можно править.

**Не обрывается.** Музыка играет при свёрнутом приложении, показывается на экране блокировки и в шторке, слушается кнопок на наушниках. На телефонах с вырезом под камеру загорается капсула — Mini Capsule у Realme, Smart Island у OPPO, Now Bar у Samsung.

## Приложения

### Android

APK подписан ключом разработчика, поэтому при установке система предупредит об «установке из неизвестного источника» — это нормально для приложений не из Google Play.

При первом запуске приложение попросит разрешение на уведомления. Оно нужно для карточки с музыкой в шторке: без него музыка играет, но управлять ею снаружи приложения не получится.

- минимальная версия: Android 6.0 (API 23)
- целевая: Android 15 (API 35)
- идентификатор: `pw.vexus.music`

### Windows

Исполняемый файл **не подписан сертификатом**, поэтому при первом запуске появится синее окно «Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**. Убрать это предупреждение можно только покупкой сертификата подписи кода.

Два варианта на выбор:

- **Setup** — обычная установка с ярлыком в меню «Пуск»;
- **Portable** — один файл, запускается откуда угодно, ничего не устанавливает.

Приложение показывает управление музыкой при наведении на значок в панели задач и открывает ссылки `vexmus://` — по ним из браузера открывается общий плейлист.

## Как устроено

Приложения — не браузер, направленный на сайт: внутри каждого лежит собранное приложение целиком, наружу уходят только запросы за данными и за самой музыкой.

| Слой | Чем сделано |
|---|---|
| Приложение | React + TypeScript, Vite |
| Windows | Electron |
| Android | Capacitor |
| Сервер | Python, FastAPI, PostgreSQL |
| Хранилище | S3 + CDN |

Тексты песен — [LRCLIB](https://lrclib.net), каталог радиостанций — [Radio Browser](https://www.radio-browser.info). Оба открытые и бесплатные.

## Вопросы и ответы

**Сколько стоит?** Нисколько. Рекламы тоже нет.

**Нужна регистрация?** В Telegram — нет, вход происходит сам. В браузере и в приложениях — почта и пароль; задать их можно в профиле внутри Telegram.

**Почему у некоторых треков нет текста?** Синхронные тексты берутся из открытого каталога, и там есть не всё. Примерно у половины треков они находятся.

**Почему радиостанций меньше, чем в каталоге?** Показываются только те, чей поток проверен и действительно играет. Остальные молча не включились бы — лучше не показывать вовсе.

**Музыка замолкает при сворачивании.** На Android дайте разрешение на уведомления: без него служба, которая держит воспроизведение, не может показать карточку и система выгружает приложение.
